# Animaties

Zet per oefening één video in deze map, met precies de bestandsnaam uit de lijst.

- Formaat: **MP4** (H.264), vierkant (bijv. 720 × 720), 5–10 seconden, loopt naadloos rond, zonder geluid.
- Ontbreekt een bestand, dan toont de app "Animatie volgt" met de uitleg in stappen.
